Title: IT Asset Management Policy (Test Document)
1. Overview

This document defines the standard operating procedures for managing IT assets within the organization using the Snipe-IT Asset Management System.

The system is used to track laptops, desktops, network equipment, and peripherals across departments.

2. Asset Lifecycle

All IT assets follow this lifecycle:

Request
Approval
Procurement
Assignment
Active Usage
Maintenance
Decommission
Disposal

Each stage must be updated in the Snipe-IT system.

3. Asset Assignment Rules
Every asset must be assigned to a single user or department.
Assets cannot remain unassigned for more than 7 days after activation.
Assignment history must be preserved for audit purposes.
4. Laptop Standards

Standard corporate laptop configurations:

Dell Latitude 5420 (8GB RAM, i5)
Dell Latitude 7420 (16GB RAM, i7)
MacBook Pro M1 (16GB RAM)

All laptops must have:

Company encryption enabled
Endpoint protection installed
Asset tag physically attached
5. Asset Tag Format

All assets must follow this format:

ABC-1234567

Where:

ABC = department code
1234567 = unique numeric identifier

Example:

IT-1002345
HR-2009834
6. Asset Status Definitions
Ready to Deploy → Available for assignment
Deployed → Assigned to user
In Repair → Under maintenance
Retired → No longer in use
7. Security Policy
Assets must not be used by unauthorized personnel.
Lost or stolen assets must be reported within 24 hours.
Sensitive data must be wiped before disposal.
8. Support Process

For asset-related issues:

Submit a ticket via IT support portal
Include asset tag and issue description
Expected response time: 24–48 hours
9. Frequently Asked Questions

Q: How do I check who owns an asset?
A: Use the Snipe-IT asset detail page or search by asset tag.

Q: What happens when an asset is retired?
A: It is removed from active inventory but remains in historical records.
